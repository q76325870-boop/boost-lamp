Автотесты используют искусственные ответы для отказа доступа, обновления сессии и источника, Range/HEAD/416, неправильного диапазона/смены файла, отмены потока, истории и лимитов. Они не заменяют проверку конкретного CDN, платной подписки, прошивки или поведения внешнего плеера.

Документ обновляется по фактам проверки. Нельзя помечать пункт пройденным только по наличию кода, скриншота или HTTP 200.

При установке исправлено описание tmpfs в Compose: строка с запятыми заключена в кавычки. CI теперь проверяет не только сборку, но и настоящий запуск Compose до healthy. На исходном ТВ версии, каталоги данных и статус установки пяти нужных приложений сохранены; Home и системные службы не менялись.
