# Проверка и границы готовности

25.10.2026 · предварительная версия 0.1.0 · без заявления о полной аппаратной совместимости.

| Проверка | Результат |
| --- | --- |
| Серверные тесты | 19 пройдено, Python 3.12 на Windows |
| JavaScript тесты | 11 пройдено, Node 24; исполняется настоящий текст плагина с контрактной моделью Lampa |
| Подключение аккаунта | Проверено на локальном сервере через сохранённую сессию владельца |
| Привязка клиента | Код → подтверждение → выдача токена проверены в настоящей браузерной Lampa |
| Каталог автора | 15 доступных видео, исходные качества и обложки загружены |
| MP4 в браузерной Lampa | 1920×1080, звук отдельно физически не оценивался |
| Перемотка и продолжение | Переходы к 305 и 125 секундам, сохранение 125 секунд, повторный старт после 125 секунд подтверждены |
| Лента | Реальная форма ответа Boosty исследована, исправление покрыто тестом; повторно показаны 15 карточек в браузерной Lampa |
| Продолжение возле конца видео | На фактической браузерной Lampa сохранены 1172,528 секунды из 1260,629, повторный старт 1172,535 секунды (93%). Прежняя тестовая позиция затем восстановлена |
| Безопасность/стабильность | 10 независимых осей и арбитраж; весь обязательный план одобрен и выполнен, повтор критиков закрыл обязательные находки. Четыре пункта оставлены в реестре технического долга REVIEW |
| Сохранность подключения при обновлении | Сессия перенесена из старого файла в SQLite, вход и история доступны после рестарта локального сервера; приватная копия до переноса сохранена вне комплекта |
| Настоящий ТВ и ViMu | Ранее проверен отдельный пробный поток через selfhost: владелец подтвердил изображение, звук и перемотку. Полный новый плагин и возврат позиции ещё не проверены |
| Новый Docker образ на Linux | Подготовлен; сборка/запуск текущего образа ещё не подтверждены |
| Закрытый подписочный ролик | Не проверен: в тестовом аккаунте нет соответствующей платной подписки |
| HLS/DASH-only | Не поддерживается |
| Длительный просмотр, сон/пробуждение ТВ | Не проверены |

Автотесты используют искусственные ответы для отказа доступа, обновления сессии и источника, Range/HEAD/416, неправильного диапазона/смены файла, отмены потока, истории и лимитов. Они не заменяют проверку конкретного CDN, платной подписки, прошивки или поведения внешнего плеера.

Документ обновляется по фактам проверки. Нельзя помечать пункт пройденным только по наличию кода, скриншота или HTTP 200.
