# План реализации и переноса

Основание: согласованная серверная архитектура и проба 25.10.2026. Открытый MP4 1080p с перемоткой проверен на selfhost и ViMu. Платного доступа для приёмки нет; это не блокирует разработку, но остаётся ограничением доказательств.

1. Контрактные тесты: импорт и refresh сессии, привязка, фильтрация прав, безопасные upstream, Range и отмена, история.
2. Сервер: FastAPI/HTTPX/SQLite; отдельные public/admin listeners, одна сессия владельца, MP4 и исходные качества без перекодирования. HLS/DASH-only — явная ошибка неподдержанного формата.
3. ES5-плагин: меню Boosty, продолжение/лента/авторы, карточки, пульт, выбор качества, локальный поток, собственная история. Существующие настройки плеера сохраняются.
4. Установка: отдельный Compose-проект и порт; существующий медиастек не изменяется. Добавление собственного плагина на ТВ — после проверки пакета.
5. Независимая панель, конкретный план исправлений, приёмка в браузере и на ТВ.
6. ZIP без секретов, SHA-256, README и инструкция в стиле исходного руководства: маршрут агента, цели/ограничения, этапы, команды, типовые ошибки, возврат и отчёт.

Исходники изолированы от существующего медиастека. Адрес сервера задаётся при установке. Админка публикуется только на loopback, для удалённого подключения используется SSH-туннель. Публичный репозиторий: https://github.com/q76325870-boop/boost-lamp.
