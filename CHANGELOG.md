# Изменения

## Обновление 25.10.2026 — выбор плеера

- Долгое нажатие на видео открывает выбор встроенного или внешнего Android-плеера, затем качества. Работает в каталоге и «Продолжить»; обычное нажатие сохраняет настройки Lampa.
- Выбор действует на один запуск. Отмена возвращает фокус, ошибка запуска освобождает поток и обработчики без перезаписи позиции.
- Добавлены проверки внешнего и внутреннего запуска, продолжения после 90%, отмены, следующего обычного запуска и ошибки приложения. 27 Node-тестов и 23 серверных теста пройдены.

## Исправление 25.10.2026 — CDN видео

- Добавлен видеодомен vkuser.net, который Boosty выдаёт для части роликов. Исправлена серверная блокировка потока UNSAFE_UPSTREAM.
- Сохранены HTTPS/443, проверка границы домена и публичности каждого IP, IP pinning/SNI и проверка каждого перенаправления. Список доменов изображений не расширялся.
- Новые проверки перенаправления между CDN, Range и отказа при private DNS; полный серверный набор — 23 теста.

## Обновление 25.10.2026 — навигация пульта

- Отдельные области фокуса: карточки, вкладки, верхняя панель Lampa. Переходы вверх/вниз сохраняют выбранную вкладку и карточку; горизонтальная навигация остаётся внутри уровня.
- Подключённое устройство скрывает кнопку «Подключение». Потеря привязки при запуске возвращает кнопку и фокус, успешная повторная привязка обновляет сохранённую страницу при возврате назад.
- Запоздавший отказ старого запроса не стирает новую привязку. Учтены оба порядка событий фокуса Lampa.
- Обновлены screenshots README: авторы, новые видео, страница автора. Изменения подготовлены только в репозитории, без обновления selfhost.

## Обновление 25.10.2026 — авторы и несколько телевизоров

- Исправлены имена и аватары авторов; добавлены описания и обложки.
- Вкладки вместо промежуточного меню-карточек; квадратная сетка авторов без серых подложек, кольцо фокуса и контрастные подписи.
- Несколько привязанных ТВ и независимые просмотры; история общая, существующие ключи сохраняются.
- Проверки этой итерации выполнены в локальном браузере без управления ТВ.

## 0.1.0 — предварительная версия, 25.10.2026

- Серверный просмотр доступных видео Boosty в Lampa: авторы, лента, продолжение, выбор исходного MP4 качества.
- Передача по запросу с Range/HEAD и повторной проверкой доступа; без архива и транскодирования.
- Подключение владельца через официальный сайт, одноразовая привязка ТВ, отдельный локальный административный порт.
- История и сессия в SQLite; транзакционное переключение аккаунта и изоляция ожидающих запросов.
- ES5 интерфейс с пультом, ограниченными страницами и контрактными проверками жизненного цикла плеера.
- Docker Compose, иллюстрированный README, инструкция установки/входа, AGENTS и передача другому агенту.
- Исправлены tmpfs в Compose и переход пульта из шапки к неполному ряду карточек; выполнена установка и проверка просмотра/продолжения на Android TV.

Результаты и непроверенные сценарии: [ACCEPTANCE](docs/ACCEPTANCE.md). Независимая проверка и отложенные пункты: [REVIEW](docs/REVIEW.md).
