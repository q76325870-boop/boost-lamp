Boosty на телевизоре

Вход выполняется на компьютере. Телевизор получает доступ только к каталогу и воспроизведению.

Ожидание подключения

1. Подключить аккаунт

Предпочтительный способ — помощник scripts/login.py: он откроет официальный сайт Boosty. Пароль вводится только там.

Если агент подготовил файл сессии только для Boosty, выберите его ниже. Он передаётся вашему серверу и не включается в комплект переноса.

2. Привязать телевизор

Откройте раздел Boosty в Lampa и выберите «Привязать телевизор». Введите показанный код. Новая привязка добавляет устройство. Ранее подключённые устройства сохраняют доступ.
