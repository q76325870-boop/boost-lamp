# Boosty для Lampa — инструкции агенту

Назначение: поток доступных владельцу видео Boosty через его сервер; ТВ показывает каталог и воспроизводит. Сначала читай README.md и docs/HANDOFF.md. Текущий запрос владельца важнее примеров и истории.

- Не устанавливай заново Lampa, TorrServer, VPN и плеер. Не отключай системные пакеты и не меняй Home в рамках установки плагина.
- Не читай и не публикуй содержимое `.env`, `state/`, `private/`, cookies и токены. Сессию нового владельца подключай отдельно. В переносимый архив эти данные не включаются.
- Деплой, доступ к ТВ и изменение сетевых правил требуют разрешения владельца в текущем чате. Разрешение с исходной системы не переносится.
- Тестовый HTTP-ответ не заменяет просмотр на настоящем ТВ. Проверяй пульт, звук, перемотку и продолжение просмотра.
- Коммиты на русском. Для существенной логики сначала тест; перед выпуском независимое review-panel. Его исправления — после согласования конкретного плана.
- Один тяжёлый процесс, общий RAM бюджет 8 ГиБ, оставлять свободными максимум из 4 ГиБ и 15% RAM. Node heap 2048 МиБ, один worker; Windows приоритет BelowNormal и не более четверти логических CPU для тяжёлых проверок.
- Runtime контейнер: один процесс, не более 1 CPU и 512 МиБ RAM. Не меняй общие лимиты Docker/WSL.
- Сохраняй проверки доступа, границы потока, закрытие соединений при отмене и защиту от запросов к частным upstream-адресам.
- Не называй платный доступ проверенным по открытому ролику. Не обещай работу HLS/DASH, если проверен только MP4.

## Проверки

`python -m pytest -q` — сервер, последовательно. `node --test --test-concurrency=1 tests/plugin.test.cjs` — интерфейс. Команды выполняются отдельно, затем браузерная и аппаратная приёмка.

## Текущий контракт

- Один аккаунт, несколько независимых привязок устройств. Новая привязка и просмотр не отзывают доступ другого ТВ. Смена аккаунта отзывает все старые привязки. История общая: последнее обновление позиции побеждает.
- По текущему запросу владельца проверки этой итерации проводить в локальном браузере, без управления ТВ. Сохранить рабочие привязки при обновлении.
